# Typography

Papers & Pixels uses DM Sans (body and controls) and Manrope (headings), distributed through Google Fonts under the SIL Open Font License.

The Latin variable WOFF2 files are bundled from `src/assets/fonts/` by Vite. The fonts are served from this website, without requests to Google Fonts from visitors' browsers. Other scripts and unsupported glyphs fall back to the system fonts.

Sources:
- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/manrope

See OFL-DM-Sans.txt and OFL-Manrope.txt for the licenses.
